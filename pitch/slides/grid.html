The same hours, for the grid

Heat and smoke days are the grid’s worst days too. The peak price runs 4–9 pm every day; the house must be cooled before it, and in smoke it stays shut, so the air conditioner runs longer.

Customer

One strip: when it is hot, when it is smoky, when it is expensive. “Cool” marks the cheap hours to pre-cool; “peak” the PG&E E-TOU-C window that CCAs like SVCE bill on.

Grid

The same day as JSON (home, alerts, plan.bms) for a home agent or a DERMS. In Sept 2020 smoke cut CAISO solar ~30% below July and hour-ahead forecasts missed it by 10–50%: the smoke hour is a signal the grid does not have.
