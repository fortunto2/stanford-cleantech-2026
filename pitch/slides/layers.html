Every plan is checked four ways

Model: hourly smoke + heat forecast, NowCast

Satellite: NASA VIIRS fires within 50 km

Ground: AirNow monitors within 25 km

Crew: reports from the people on site

Rulebook

Cal/OSHA thresholds as data, one file per state

Plan + log

Per site, per shift, with confidence

No sensors of our own. The forecast model covers every grid cell, but a forty-kilometre smoke model reads low right next to a fire, so every plan is checked. NASA's VIIRS satellites flag active fires; one within fifty kilometres puts a warning on the plan. AirNow's regulatory monitors within twenty-five kilometres are compared with the model; if they disagree by more than one and a half times, the forecast is pulled toward the monitor, never below half, because this is a safety tool. And the crew's own reports are the fourth check. Then the rulebook, which is just data: one file per jurisdiction, so Oregon or Spain is a new file, not new code.
